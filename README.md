# Vodafone × Disney+ – Claw game prototype (mobile 2v1)

Klikací prototyp vánoční in-store aktivace: hra i ovládání běží v mobilu zákazníka.

**Živá verze:** https://hyhng.github.io/vodafone-claw-prototype/

## Flow
1. Intro → onboarding (4 kroky, zpět/další)
2. Hra – zamíření (kývání / joystick / tah prstem) a CHYŤ, 20 s timer
3. Rozbalení dárku → voucher vylétne z krabice
4. Voucher s živým časem a ochranným pásem (proti screenshotu), předání personálem

## Ovládání prototypu
- Panel vpravo (desktop) / ikona vpravo nahoře (mobil): kroky flow, mechanika, chycení, magnet, čas, simulace chyb
- Klávesy: šipky = pohyb, mezerník = CHYŤ, R = od začátku
- PIN prodejny (demo): 1234
